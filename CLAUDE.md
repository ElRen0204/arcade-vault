# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Status

`create-next-app` scaffold (App Router, TypeScript, Tailwind v4) with the global Arcade Vault retro-neon theme applied (branch `01-styles`). `app/page.tsx` is only a minimal hero used to check the theme; the real screens still have to be ported from `references/templates/*.jsx` (nav, biblioteca, detalle, reproductor, auth, salon, data). There is no test framework.

`references/templates/` holds the original prototype (`Arcade Vault.html`, `styles.css`, JSX screens). Treat it as the visual source of truth.

## Architecture notes

- Versions are very new (Next 16.4, React 19.3) and may differ from what you know. Bundled docs live in `node_modules/next/dist/docs/` (`01-app` is the App Router) — consult them before using unfamiliar APIs.
- `next.config.ts` enables `cacheComponents`, `partialPrefetching` and `experimental.agentFeedback`. With `cacheComponents`, dynamic/uncached data access must sit inside `<Suspense>` or use the caching directives; this affects how pages and layouts fetch data.
- Tailwind v4 is wired through Turbopack: `next.config.ts` has a `turbopack.rules` entry running `@tailwindcss/turbopack` on `*.css`. Styling is configured in CSS (`app/globals.css` with `@import "tailwindcss"` and `@theme inline`), not a `tailwind.config` file.
- Theme: `app/globals.css` is a copy of `references/templates/styles.css` (keep them in sync). It is dark-only (no `prefers-color-scheme`). Palette and fonts are CSS variables in `:root` (`--bg`, `--ink`, `--cyan`, `--magenta`, `--yellow`, `--green`, `--gold`, `--line`, `--pixel`, `--mono`, ...), also exposed to Tailwind through `@theme inline` (`text-cyan`, `bg-arcade-bg-2`, `font-pixel`, ...). The reset lives in `@layer base` and all component classes (`.btn`, `.card`, `.av-nav`, `.crt`, `.modal`, `.leaderboard`, `.cover-*`, neon/`.pixel` text, ...) in `@layer components`, so Tailwind utilities can still override them. Prefer reusing these classes over re-styling with utilities.
- `app/layout.tsx` loads Press Start 2P, JetBrains Mono (400/500/700) and Courier Prime (400/700) via `next/font/google`, exposed as `--font-pixel`, `--font-jetbrains-mono` and `--font-courier-prime` (consumed by `--pixel` / `--mono`). It renders the `.av-bg` and `.av-noise` background layers and wraps children in `.av-app` (replaces the template's `#root`; Next has no such element). Pages should use `<main className="av-main">`. It uses the global `LayoutProps<"/">` type (generated by Next, no import needed).
- Path alias: `@/*` maps to the repo root (`tsconfig.json`).
