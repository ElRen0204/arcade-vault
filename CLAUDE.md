# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Status

Fresh `create-next-app` scaffold (App Router, TypeScript, Tailwind v4). `app/page.tsx` is still the default template and `app/layout.tsx` still has the default "Create Next App" metadata. There is no test framework and no git repository yet.

## Commands

- `npm run dev` — dev server (Turbopack)
- `npm run build` / `npm run start` — production build / serve
- `npm run lint` — ESLint (flat config, `eslint.config.mjs`, extends `eslint-config-next` core-web-vitals + typescript). Pass paths to lint a single file, e.g. `npx eslint app/page.tsx`
- Type check: `npx tsc --noEmit`

## Architecture notes

- Versions are very new (Next 16.4, React 19.3) and may differ from what you know. Bundled docs live in `node_modules/next/dist/docs/` (`01-app` is the App Router) — consult them before using unfamiliar APIs.
- `next.config.ts` enables `cacheComponents`, `partialPrefetching` and `experimental.agentFeedback`. With `cacheComponents`, dynamic/uncached data access must sit inside `<Suspense>` or use the caching directives; this affects how pages and layouts fetch data.
- Tailwind v4 is wired through Turbopack: `next.config.ts` has a `turbopack.rules` entry running `@tailwindcss/turbopack` on `*.css`. Styling is configured in CSS (`app/globals.css` with `@import "tailwindcss"` and `@theme inline`), not a `tailwind.config` file. Light/dark colors are CSS variables (`--background`, `--foreground`) switched via `prefers-color-scheme`.
- `app/layout.tsx` loads Geist / Geist Mono via `next/font/google` and exposes them as `--font-geist-sans` / `--font-geist-mono`. It uses the global `LayoutProps<"/">` type (generated by Next, no import needed).
- Path alias: `@/*` maps to the repo root (`tsconfig.json`).
